# 小学一年级家长需求雷达人工校准标注说明

## 任务目标

本轮不是重新做需求分析，而是校准当前页面的信噪比和聚类准确性：哪些评论不该进证据池，哪些评论分错簇，哪些机会卡片证据不足或需要拆分/合并。

## 分工

- 婷婷：主看评论是否有效、当前一级主题/需求簇是否正确、哪些簇噪声高或需要拆分合并。
- 伟峰：主看评论是否支撑当前机会卡片、需求和供给是否连得上、机会卡片是否过泛或需要拆分/降级。
- 两人先共同标注 overlap_batch=是 的 84 条，用于口径对齐；口径对齐后再各自标注分配给自己的样本。

## 必填字段和选项

### mark_is_valid_comment
选项：是 / 否 / 不确定

有效评论：能识别出家长的真实问题、需求、痛点、吐槽、经验反馈、求助、解决办法或对现有供给的评价。

### mark_invalid_reason
当 mark_is_valid_comment=否 时填写。
选项：纯表情/无意义短评 / 单纯夸赞 / 无上下文求资料或蹲 / 明显营销引流 / 抽奖互动 / 与小一家长场景无关 / 语境不足 / 重复 / 其他

### mark_belongs_to_current_theme
选项：是 / 否 / 不确定

判断评论是否属于 current_theme。

### mark_correct_theme
当当前主题错误时填写建议主题；如果建议新增主题，写“新增：主题名”。

### mark_belongs_to_current_cluster
选项：是 / 否 / 不确定

判断评论是否属于 current_cluster。

### mark_correct_cluster
当当前簇错误时填写建议簇；如果建议新增簇，写“新增：簇名”。如果建议拆簇，写“拆分：A / B”。如果建议合并，写“合并到：簇名”。

### mark_need_type
选项：痛点 / 需求 / 痒点 / 经验反馈 / 供给评价 / 反例 / 无效

### mark_user_scene
可自由填写短语，例如：作业陪伴 / 拼音学习 / 读题 / 托管选择 / 老师反馈 / 家校沟通 / 学习机购买 / 入学适应。

### mark_current_solution_or_supply
如果评论提到当前办法或供给，填写，例如：练习册 / 资料包 / 老师 / 托管 / 一对一 / 学习机 / 测评 / 医院 / 家长自己陪。

### mark_supports_opportunity
选项：强支撑 / 弱支撑 / 不支撑 / 不确定

强支撑：评论明确表达该机会卡片的核心场景和问题。
弱支撑：相关，但只能说明背景或边缘问题。
不支撑：评论虽然在同主题下，但不能支撑当前机会判断。

### mark_noise_level
选项：0无噪声 / 1轻微噪声 / 2明显噪声 / 3应剔除

### mark_action_suggestion
选项：保留 / 剔除 / 改簇 / 拆簇 / 合并簇 / 降级为背景 / 需补采 / 需讨论

### mark_notes
自由备注，写清楚为什么。

## 回传方式

请回传：

1. 标注后的 CSV。
2. 一份 1 页以内 summary，包含：噪声最多的簇、错分最多的簇、建议拆分/合并的簇、建议移出机会卡片的簇、新增机会建议。
