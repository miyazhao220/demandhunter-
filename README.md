# 小学一年级家长机会雷达 v0.0.3

这是 `parent-radar-pilot` 当前可分享的静态发布包。本版基于婷婷、伟峰人工标注样本做了规则校准，重点提升评论证据与主题/需求簇的匹配准确度。

## 文件

- `index.html`：机会卡片页面。
- `grade1-data.json`：页面读取的已归类评论证据数据。

## 本地预览

从 `opportunity-radar` 目录启动静态服务：

```bash
python3 -m http.server 8106
```

访问：

```text
http://localhost:8106/parent-radar-pilot/published/grade1/
```

## 页面结构

页面使用「机会卡片 -> 需求簇 -> 评论证据」的渐进展开结构：

- 首屏只展示机会列表。
- 点击机会卡片，展开「谁 / 场景 / 问题 / 当前办法 / 现有供给 / 缺口 / 待验证」。
- 点击关联需求簇，展开该簇评论证据。
- 评论证据默认展示 6 条，可继续加载更多或展开全部。

## 证据口径

- 只把评论/回复作为用户证据。
- 帖子/视频标题只作为评论上下文，不作为痛点证据。
- 数据来自小红书和抖音公开内容接口样本。
- 当前是初步收集和结构化展示，机会判断、供给缺口和待验证项仍需人工校验。

## v0.0.3 校准变化

- 增强低信号过滤：纯互动、泛夸赞、调侃、无自家场景的一般建议、供给方/行业经验评论不进入需求证据。
- 增强营销过滤：机构自荐、托管/培训/课程招生、私信咨询、资料领取类评论提前剔除。
- 修正主题路由：学习桌、护眼灯、学习机、App 等优先归入「学习空间、硬件和工具选择」；兴趣班、画画、书法、运动类优先归入「兴趣班与综合素养取舍」。
- 收紧资源簇：只保留明确索取电子版、资料、试卷、课件、软件、链接、教材等评论。
- 收紧专注力训练簇：需要评论正文同时包含注意力/专注/走神/感统等上下文和训练方法信号。
- 收紧校园安全簇：需要具体事件、求助或处置语境；单纯观点、倡议或泛化评论不作为自家痛点证据。
