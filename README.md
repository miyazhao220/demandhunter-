# 小学一年级家长机会雷达初步收集版

这是 `parent-radar-pilot` 当前可分享的静态发布包。

## 文件

- `index.html`：机会卡片页面。
- `grade1-data.json`：页面读取的已归类评论证据数据。

## 本地预览

从 `opportunity-radar` 目录启动静态服务：

```bash
python3 -m http.server 8106
```

访问：

```text
http://localhost:8106/parent-radar-pilot/published/grade1/
```

## 页面结构

页面使用「机会卡片 -> 需求簇 -> 评论证据」的渐进展开结构：

- 首屏只展示机会列表。
- 点击机会卡片，展开「谁 / 场景 / 问题 / 当前办法 / 现有供给 / 缺口 / 待验证」。
- 点击关联需求簇，展开该簇评论证据。
- 评论证据默认展示 6 条，可继续加载更多或展开全部。

## 证据口径

- 只把评论/回复作为用户证据。
- 帖子/视频标题只作为评论上下文，不作为痛点证据。
- 数据来自小红书和抖音公开内容接口样本。
- 当前是初步收集和结构化展示，机会判断、供给缺口和待验证项仍需人工校验。
